# NIGHTFALL / Drive City

기존 NIGHTFALL과 별도인 웹 싱글플레이 FPS입니다. 기존 게임의 계정과 저장 데이터에는 연결하지 않습니다.

1. [플레이 페이지](https://mingeon101.github.io/nightfall-drive-city/)를 엽니다.
2. **도시 맵 ZIP 선택**으로 `drive-for-speed-map.zip`을 고릅니다. 압축을 풀 필요가 없습니다.
3. 로딩이 끝나면 **작전 시작**을 누릅니다.

WASD 이동, Shift 달리기, Space 점프, 마우스 사격, R 재장전, M 지도, Esc 일시정지. 터치 화면에서는 드래그로 시점을 돌리고 화면 버튼을 사용합니다. 순찰 드론을 모두 제거한 뒤에도 도시를 탐색할 수 있습니다.

맵 파일은 로컬에서 읽습니다. 원본 ZIP과 그 안의 모델·텍스처는 저장소에 포함하지 않습니다. 원본 맵은 [drive for speed - map](https://sketchfab.com/3d-models/drive-for-speed-map-69235d34307f4df894492f13d8dded93)에 amogusstrikesback2가 게시했으며, 게시 페이지는 CC Attribution으로 표시합니다. 게임은 FBX의 축과 중심을 보정하고 도로 충돌 및 게임 요소를 추가합니다. WebGL 2와 외부 3D 라이브러리를 불러올 인터넷 연결이 필요합니다.
