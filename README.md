# NIGHTFALL · Drive City

[플레이](https://mingeon101.github.io/nightfall-drive-city/)

Drive City 전용 싱글플레이입니다. 페이지를 열면 맵을 자동으로 다운로드하고 검증합니다. **Drive City 작전 시작**을 눌러 입장하세요. 약 50MB인 원본 ZIP은 GitHub 웹 업로드 크기에 맞춰 나눈 뒤 브라우저에서 원래 바이트 순서대로 합칩니다.

- WASD 이동, Space 점프, E 상호작용 및 탑승, 1–5 무기, I 인벤토리, M 지도.
- 지도에서 M은 2호선 역, +는 병원, C는 편의점, A는 공항, B는 군사기지입니다. 역 입구에서 E로 목적지를 고른 뒤 전동차에 승차하세요. 공항 활주로에는 수송기가 있고 군사기지에는 장비와 보급품이 있습니다.
